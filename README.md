# CSVデータ表示システム テンプレート記述マニュアル

CSVデータを読み込み、リストページや詳細ページとして表示するためのテンプレート記述方法をまとめています。

このシステムでは、主にCSVの各項目を `$data` として取得し、PHPテンプレート内で表示します。

---

# 1. ファイル構成

| ファイル          | 用途            |
| ------------- | ------------- |
| `index.php`   | 基本設定・データ処理    |
| `list.php`    | リストページのテンプレート |
| `details.php` | 詳細ページのテンプレート  |
| `csv.php`     | その他のCSV関連処理   |

---

# 2. 基本的な項目の表示

CSVの項目は、基本的に以下の形式で表示します。

```php
<?= $data["★項目名★"]; ?>
```

`★項目名★`の部分を、CSVの項目名に変更してください。

### 例

```php
<?= $data["店舗名"]; ?>
```

---

# 3. 値が空の場合の処理

## 空の場合は何も表示しない

```php
<?= $data["★項目名★"] ?? ''; ?>
```

---

## 空の場合に指定した文字列を表示する

```php
<?= $data["★項目名★"] ?? 'ない場合の文字列'; ?>
```

### 例

```php
<?= $data["住所"] ?? '住所情報なし'; ?>
```

---

## 複数の項目を順番に確認する

最初の項目が空の場合、次の項目を使用します。

```php
<?= $data["★項目名★"] ?? $data["☆項目名☆"] ?? 'ない場合の文字列'; ?>
```

---

# 4. 改行を `<br>` に変換して表示する

CSV内の改行をHTML上でも改行として表示する場合。

```php
<?= str_replace("\n", "<br>", $data["★項目名★"]); ?>
```

---

# 5. 関連CSVのデータを表示する

関連するCSVデータは、CSV名を指定して取得します。

```php
<?= $data["★関連CSV名★"]["★項目名★"]; ?>
```

### 例

```php
<?= $data["店舗情報"]["住所"]; ?>
```

---

# 6. `<?php echo` の省略

以下の2つは同じ意味です。

```php
<?php echo $data["項目名"]; ?>
```

省略形：

```php
<?= $data["項目名"]; ?>
```

テンプレート内では、基本的に省略形の `<?= ?>` を使用できます。

---

# 7. 詳細ページへのリンク

各データのIDを使用して詳細ページへリンクします。

```php
<a href="./?c=<?= $data[$dbId] ?>">
```

---

# 8. リスト表示

CSVデータを指定件数ずつ表示します。

```php
<?php for ($i = $pos; $i < $pos + $items && $i < count($csv); ++$i): $data = $csv[$i]; if ($data): ?>
```

ここに表示する内容を記述します。

```php
【内容】
```

最後に閉じます。

```php
<?php endif; endfor; ?>
```

---

# 9. ページネーション

前後のページへのリンクを表示します。

## 前のページ

```php
<?php if ($pos >= $items): ?>
<a href="./<?= getQuery(["p" => $pos - $items]); ?>">←</a>
<?php endif ?>
```

## 次のページ

```php
<?php if ($pos + $items < count($csv)): ?>
<a href="./<?= getQuery(["p" => $pos + $items]); ?>">→</a>
<?php endif ?>
```

---

# 10. 検索キーワード `?q=` の表示

URLの `q` パラメータを表示します。

```php
<?php if (!empty($_GET["q"])) : echo "【", htmlentities($_GET["q"]), "】"; endif; ?>
```

### 表示例

```text
【和歌山】
```

---

## カンマ区切りの後半だけ表示する

```php
<?php if (!empty($_GET["q"])) : echo "【", htmlentities(preg_replace("/^.*,/", "", $_GET["q"])), "】"; endif; ?>
```

例えば、

```text
カテゴリ,和歌山
```

の場合、

```text
【和歌山】
```

を表示します。

---

# 11. DB名の取得

URLの `db` パラメータを取得します。

```php
<?= preg_replace("/\W/", "", $_GET['db'] ?? "") ?>
```

不要な文字を除去して使用します。

---

# 12. 基本的なリンク

項目名をリンク文字として表示します。

```php
<a href="./?c=<?= $data[$dbId] ?>"><?= $data["項目名"]; ?></a>
```

---

# 13. 絞り込みリンク

特定の項目を指定して絞り込みます。

```php
<a href="./?q=★項目名★,▲">▲</a>
```

項目名が `▲` の場合、完全一致で絞り込みます。

複数の条件を指定する場合は `/` で区切ります。

### 例

```text
▲/#/■
```

---

# 14. 値がある場合のみ表示する

## 1項目がある場合

```php
<?php if (!empty($data["★関連CSV名★"]["★項目名★"])): ?>
```

```php
<?php endif; ?>
```

---

## AとBの両方がある場合

```php
<?php if (!empty($data["★関連CSV名★"]["★項目名A★"]) && !empty($data["★関連CSV名★"]["★項目名B★"])): ?>
```

---

## AまたはBのどちらかがある場合

```php
<?php if (!empty($data["★関連CSV名★"]["★項目名A★"]) || !empty($data["★関連CSV名★"]["★項目名B★"])): ?>
```

---

## それ以外の場合を指定する

```php
<?php if (!empty($data["★関連CSV名★"]["★項目名★"])): ?>

<?php else : ?>

<?php endif; ?>
```

---

# 15. 値がない場合のみ表示する

## 1項目が空の場合

```php
<?php if (empty($data["★関連CSV名★"]["★項目名★"])): ?>
```

```php
<?php endif; ?>
```

---

## AとBの両方が空の場合

```php
<?php if (empty($data["★関連CSV名★"]["★項目名A★"]) && empty($data["★関連CSV名★"]["★項目名B★"])): ?>
```

---

## AまたはBのどちらかが空の場合

```php
<?php if (empty($data["★関連CSV名★"]["★項目名A★"]) || empty($data["★関連CSV名★"]["★項目名B★"])): ?>
```

---

# 16. 値が完全一致する場合

`★項目名★`の値が `▲` の場合は `# ■`、それ以外の場合は `◆` を表示します。

```php
<?php if ($data["★項目名★"] === "▲"): ?>
# ■
<?php else : ?>
◆
<?php endif; ?>
```

---

## 関連CSVも含めて確認する

```php
<?php if (($data["★項目名★"] ?? $data["★関連CSV名★"]["★項目名★"] ?? '') === "▲"): ?>
# ■
<?php else : ?>
◆
<?php endif; ?>
```

---

# 17. 大文字・小文字を区別せずに完全一致

`strcasecmp()`を使用します。

```php
<?php if (!strcasecmp($data["★項目名★"], "▲")): ?>
# ■
<?php else : ?>
◆
<?php endif; ?>
```

関連CSVも確認する場合：

```php
<?php if (!strcasecmp($data["★項目名★"] ?? $data["★関連CSV名★"]["★項目名★"] ?? '', "▲")): ?>
# ■
<?php else : ?>
◆
<?php endif; ?>
```

---

# 18. 値に指定した文字が含まれる場合

`▲`という文字列が含まれている場合。

```php
<?php if (stripos($data["★項目名★"], "▲") !== false): ?>
# ■
<?php else : ?>
◆
<?php endif; ?>
```

関連CSVも確認する場合：

```php
<?php if (stripos($data["★項目名★"] ?? $data["★関連CSV名★"]["★項目名★"] ?? '', "▲") !== false): ?>
# ■
<?php else : ?>
◆
<?php endif; ?>
```

---

# 19. 値が指定した文字から始まる場合

値が `▲` から始まる場合。

```php
<?php if (stripos($data["★項目名★"], "▲") === 0): ?>
# ■
<?php else : ?>
◆
<?php endif; ?>
```

関連CSVも確認する場合：

```php
<?php if (stripos($data["★項目名★"] ?? $data["★関連CSV名★"]["★項目名★"] ?? '', "▲") === 0): ?>
# ■
<?php else : ?>
◆
<?php endif; ?>
```

---

# 20. URLかどうかを判定する

値が `https://` または `http://` から始まる場合。

```php
<?php if (preg_match("/^https?:\/\//", $data["★項目名★"])): ?>
# ■
<?php else : ?>
◆
<?php endif; ?>
```

---

# 21. DB指定がある場合

URLに `?db=` が指定されている場合。

```php
<?php if (!empty($_GET["db"])): ?>

<?php else : ?>

<?php endif; ?>
```

---

# 22. DB指定がない場合

URLに `?db=` が指定されていない場合。

```php
<?php if (empty($_GET["db"])): ?>

<?php else : ?>

<?php endif; ?>
```

# 23. 日付の表示形式を変更する

CSVの日付をPHPで表示形式に変更できます。

## 月日だけ表示

```php
<?= date("n月j日", strtotime($data["★年月日★"])) ?>
```

### 表示例

```text
9月1日
```

---

# 24. 曜日の表示

曜日配列を設定している場合、曜日を表示できます。

```php
<?= $wdays[(new DateTime($data["★年月日★"]))->format('w')]; ?>
```

# 25. 項目の前後に文字を追加する

## 項目の後ろに文字を追加

```php
<?= $data["★項目名★"], "★文字★"; ?>
```

---

## 項目の前に文字を追加

```php
<?= "★文字★", $data["★項目名★"]; ?>
```

---

## 項目の前後に文字を追加

```php
<?= "★文字★", $data["★項目名★"], "★文字★"; ?>
```

# 26. 値がある場合・ない場合で表示を変更する

## 空の場合だけ文字を表示

```php
<?= empty($data["★項目名★"]) ? "★なしのときだけ★" : $data["★項目名★"] . "★あるときだけ★"; ?>
```

---

## 値がある場合に前へ文字を追加

```php
<?= empty($data["★項目名★"]) ? "★なしのときだけ★" : "★あるときだけ★" . $data["★項目名★"]; ?>
```

---

## 値がある場合に前後へ文字を追加

```php
<?= empty($data["★項目名★"]) ? "★なしのときだけ★" : "★あるときだけ★" . $data["★項目名★"] . "★あるときだけ★"; ?>
```

---

# 27. 緯度・経度・ズームを表示する

関連CSVから地図情報を取得します。

```php
<?= $data["★関連CSV名★"]["★緯度★"], ",", $data["★関連CSV名★"]["★経度★"], ",", $data["★関連CSV名★"]["★ズーム★"] ?? 16; ?>
```

ズーム値がない場合は `16` を使用します。

# 29. 数字の表示

## 1. カンマ区切り

例：`39,800円`

```php
<?= number_format(get_number($data["★項目名★"])), '円'; ?>
```

---

## 2. 単位を自動で付加

例：`3万9,800円`

```php
<?= number_unit($data["★項目名★"]), '円'; ?>
```

---

## 3. 万円単位で表示

```php
<?= number_man($data["★項目名★"]), '円'; ?>
```

# 項目名の置き換えについて

このマニュアル内で使用している以下の表記は、実際のCSV項目名などに変更して使用します。

| 表記         | 意味                |
| ---------- | ----------------- |
| `★項目名★`    | CSVの項目名           |
| `☆項目名☆`    | 代替として使用する項目名      |
| `★関連CSV名★` | 関連付けられているCSV名     |
| `★文字★`     | 任意で表示する文字         |
| `▲`        | 判定する値             |
| `# ■`      | 条件に一致した場合の表示内容    |
| `◆`        | 条件に一致しなかった場合の表示内容 |

---

# 補足

テンプレートを作成する際は、基本的に以下の流れで記述します。

```text
1. CSVの項目を取得する
        ↓
2. 必要に応じて空欄を判定する
        ↓
3. 条件によって表示を変更する
        ↓
4. リスト・詳細ページとして表示する
```

基本的なデータ表示は、

```php
<?= $data["項目名"]; ?>
```

を中心に、`if`、`empty()`、`??`、`date()`などを組み合わせて作成します。
